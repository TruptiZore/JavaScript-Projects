# JavaScript-Projects
# 1. Expense Tracker

A simple web-based **Expense Tracker** built using JavaScript. It allows users to manage their income and expenses, calculate their current balance, and view transaction history. Add income and expenses, Automatically calculate balance, Display total income, Display total expenses, View transaction history, Simple and user-friendly interface, Real-time transaction updates.

* CSS3<br>
* JavaScript<br>

# 3. Tic-Tac-Toe

A simple web-based Tic-Tac-Toe Game built using JavaScript. It is a two-player game where players take turns placing X and O on a 3×3 game board. The game automatically checks for a winner or draw, Displays the current player's turn, Restart game option and displays the result.
<br><br>
